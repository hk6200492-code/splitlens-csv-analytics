How to interpret the results

The difference is the second category’s mean minus the first’s. The adjusted comparison gives both categories the same segment mix, weighted by pooled row counts in segments containing both categories. A reversal requires every segment to show the opposite direction from the overall difference.

The machine learning model predicts an individual outcome using the average for its segment. Each test row is left out of its own training set. Error reduction compares squared prediction error with a model that uses only the overall training mean. Negative values mean the segment model performed worse. These are descriptive associations.

CSV format: one observation per row, a two-category comparison, a numeric outcome and a categorical segment. For conversion rates, enter 1 for a conversion and 0 otherwise. Empty analysis fields are excluded. The demo contains fictional campaign visitors.
